# Analyst Bot User Guide

Use Ari when a business request needs a first-pass technical scope and manday estimate.

Start by adding the customer name, requester, business unit, and tool or project name. Ari saves drafted user stories under that customer when storage is configured.

## New Tool

Choose **New tool** when the request is for a fresh application, workflow, dashboard, portal, or mobile/web tool.

Fill in the business problem, desired outcome, users, requested features, and any known reports or integrations.

## Extension

Choose **Extension** when the request changes an existing system.

Add at least one current-system reference:

- repository link
- documentation link
- system owner notes
- short description of the current tool

Upload any supporting documentation if available.

## Ari's Questions

Before generating the estimate, Ari may ask up to three short questions that help sharpen costing. If the request has a workflow, Ari will try to ask about what happens first, next, and last. Answer what you know. If you do not know, choose **I don't know** and continue.

## Reading The Estimate

The manday range is an early planning estimate. Open questions and risks show the items most likely to move the estimate up or down.

Ari also shows a visual process flow when one is relevant and drafts user stories that can be reused for the customer.

Use the recommendation to decide whether the work is ready for delivery planning, should be split into phases, or needs discovery first.

## Sending To Lex

Once Ari has an estimate, click **Send to Lex**.

Review the contract handoff fields, select the supplier, and attach any reference contract or user stories file. When you create the Lex contract, Ari privately asks what daily rate to use, calculates the one-time total, then sends the package to Lex for contract drafting.

If Ari has a process flow, it is sent to Lex as **Appendix Process Flow**.
